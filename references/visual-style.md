# Visual and IP Reference

## Default visual tone

Professional, restrained, publication-adjacent, and legible.

Prefer:
- strong typography;
- clean diagrams;
- readable plots;
- restrained motion;
- consistent spacing and framing;
- visible provenance on evidence shots.

Avoid:
- fabricated dashboards;
- pseudo-data decoration;
- cyberpunk styling by default;
- excessive cinematic effects;
- unreadable motion graphics;
- fake paper figures;
- gratuitous character acting.

## 勤劳牛 / 发疯马

If the project uses the default IP:

### 勤劳牛
- role: evidence-oriented, patient, anomaly-sensitive;
- behavior: observe, compare, point, correct, qualify;
- never substitutes for a paper result.

### 发疯马
- role: intuition, impatience, common misunderstanding, skepticism;
- behavior: ask, jump to conclusions, challenge, react;
- never acts as an invented villain or unverified institution.

Visual continuity requirements should be stored in a project-specific character bible when actual reference images exist.

Do not claim the IP is visually locked unless reference images are present.
